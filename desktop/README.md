# JARVIS Desktop — התקנה והפעלה

זו האפליקציה שנותנת לג'רביס שליטה אמיתית במחשב: לראות את המסך, ללחוץ, להקליד, לפתוח תוכנות, לנהל חלונות ולשלוח הודעות.

> **חשוב:** דף האינטרנט של ג'רביס (GitHub Pages) **לא** יכול לשלוט במחשב — דפדפן חוסם את זה מסיבות אבטחה. רק האפליקציה הזו יכולה. הדף משמש כ"אוזניים" (זיהוי דיבור בעברית) והאפליקציה כ"ידיים".

---

## התקנה — קובץ אחד

1. פתח את **`INSTALL-JARVIS.bat`** שבתיקייה הראשית של הפרויקט ב-GitHub, לחץ על כפתור **Raw** ושמור את הקובץ למחשב (Ctrl+S).
2. לחץ עליו פעמיים.

זהו. הוא מתקין את Node.js אם חסר, מוריד את הגרסה האחרונה ל-`C:\Users\<שם>\JARVIS`, מתקין את הרכיבים, יוצר קיצור דרך בשם **JARVIS** על שולחן העבודה, ופותח את האפליקציה. ההתקנה הראשונה לוקחת 2-3 דקות.

מכאן והלאה פשוט לוחצים על הקיצור **JARVIS** בשולחן העבודה.

להתקנה מחדש או לעדכון לגרסה חדשה — מריצים שוב את אותו `INSTALL-JARVIS.bat`. ההגדרות ואנשי הקשר לא נמחקים.

> **התקנה ידנית, אם מעדיפים:** התקן Node.js LTS מ-<https://nodejs.org>, הורד את הריפו (Code ← Download ZIP), חלץ, והרץ `desktop\START-JARVIS.bat`.

## הגדרה ראשונית

בפתיחה הראשונה האפליקציה שואלת שתי שאלות על המסך:

1. **המוח** — חינמי או Claude:
   - **חינמי (Cloudflare Workers AI)** — 0 ₪ תמיד. מכסה יומית של 10,000 "נוירונים" — בערך 40 שאלות פשוטות או 3-4 משימות מורכבות במחשב — שמתאפסת כל יום. כשהיא נגמרת ג'רביס אומר את זה וחוזר מחר; אין שום חיוב. צריך פעם אחת חשבון חינמי ב-<https://dash.cloudflare.com> (בלי כרטיס אשראי): **Account ID** מהעמוד הראשי, ו-**API Token** מ-Profile ← API Tokens ← Create Token ← תבנית **Workers AI**.
   - **Claude** — החכם ביותר, בתשלום לפי שימוש. מפתח מ-<https://console.anthropic.com/settings/keys>.

   המוח החינמי הוא מודל פתוח קטן יותר, אז במשימות מסך ארוכות הוא לפעמים פחות מדויק. הכל חוץ מזה זהה: שליטה במחשב, הודעות, קול, אישורים. **חיבורים (Connectors)** עובדים רק עם Claude.
2. **מה מותר לג'רביס** — "שליטה מלאה" (מומלץ) או "צפייה בלבד".

זה הכל. אפשר לשנות הכל אחר כך בכפתור **S**.

### לחיבור הקול צריך גם

בכפתור **S** יש שדה **Connection Token**. העתק אותו — הוא נדרש כדי לחבר את הקול דרך Chrome (ראה בסעיף הבא).

### חיבור הקול (טאב Chrome)

זיהוי דיבור בעברית עובד רק ב-Chrome האמיתי, לא בתוך האפליקציה. לכן:

1. פתח את דף ג'רביס ב-Chrome
2. הדבק שם את ה-**Connection Token** מההגדרות
3. אשר גישה למיקרופון
4. הנורית תיהפך לירוקה — ג'רביס מחובר

עכשיו תגיד **"ג'רביס"** ואחריו את הבקשה. הדף שומע, האפליקציה מבצעת.

השאר את הטאב פתוח ברקע. בלעדיו הכל עדיין עובד — פשוט תקליד באפליקציה במקום לדבר.

## חיבורים לשירותים (Connectors)

כפתור **C** באפליקציה. אפשר לחבר את ג'רביס לשרתי MCP מרוחקים — Notion, Linear, Sentry וכל שירות אחר שמפרסם שרת MCP — ואז יהיו לו הכלים של השירות הזה.

להוספה: שם, כתובת ה-https של השרת, וטוקן אם השירות דורש. ג'רביס יגלה אילו כלים יש בשרת ויציג אותם.

> **הבדל חשוב מהכלים המקומיים:** הכלים של Connector רצים בשרתים של Anthropic, לא במחשב שלך. לכן **דיאלוג האישור לא חל עליהם** — כל כלי שתסמן, ג'רביס יוכל להפעיל בלי לשאול.
>
> בגלל זה חיבור חדש לא מפעיל שום כלי עד שתבחר. אחרי הגילוי ג'רביס מסמן מראש רק כלים ששמם נראה כמו קריאה בלבד (get, list, search וכו') — זה ניחוש לפי שם, אז עבור על הרשימה בעצמך. כל הפעלה של כלי כזה נרשמת ביומן (כפתור **L**).

## רמות הרשאה

ג'רביס לא שואל על כל דבר. הוא שואל רק כשצריך:

| רמה | מה זה | מה קורה |
|---|---|---|
| **SAFE** | לראות מסך, לפתוח אפליקציה, לגלול, למקד חלון | קורה לבד |
| **ASK** | ללחוץ, להקליד, לסגור חלון, לקרוא הודעות | אישור — ואפשר "אשר הכל למשימה הזו" |
| **CONFIRM** | לשלוח הודעה או מייל | אישור נפרד לכל הודעה, עם הנמען והטקסט המלא |
| **HIGH RISK** | למחוק קובץ, להריץ פקודה | אישור נפרד בכל פעם |
| **BLOCKED** | רכישות, תשלומים, כרטיס אשראי, ביטול אנטי-וירוס | **חסום תמיד. אין דרך לאשר.** |

### עצירת חירום

**Ctrl+Shift+Esc** — עוצר הכל מיד, מכל מקום, גם באמצע פעולה. גם כפתור **STOP** האדום באפליקציה.

---

## מצבים

- **SAFE** — ג'רביס רואה וקורא, אבל לא נוגע. טוב לבדיקה.
- **ASSISTANT** — שליטה מלאה, עם האישורים שבטבלה למעלה. זה המצב הרגיל.

מחליפים בלחיצה על תג המצב למעלה, או מתפריט הטריי.

---

## איפה הדברים נשמרים

הכל מקומי אצלך, כלום לא עולה לענן:

```
C:\Users\<שם>\.jarvis\
  config.json     הגדרות + מפתחות
  contacts.json   אנשי קשר
  workspace\      קבצים שג'רביס יוצר
  logs\           יומן פעולות (מה עשה ומתי)
```

את יומן הפעולות אפשר לראות בכפתור **L** באפליקציה.

## פתרון תקלות

**"node is not recognized"** — Node.js לא מותקן, או שצריך לסגור ולפתוח מחדש את חלון ה-cmd אחרי ההתקנה.

**האפליקציה נפתחת אבל לא עונה** — כנראה חסר API key. לחץ S ובדוק.

**"Speech recognition not available"** — נורמלי בתוך האפליקציה. הקול עובד רק בטאב Chrome, ראה למעלה.

**ג'רביס לא לוחץ כלום** — בדוק שהמצב הוא ASSISTANT ולא SAFE.

**הנורית בדף לא נהיית ירוקה** — ודא שהאפליקציה רצה, ושה-Token שהדבקת זהה לזה שבהגדרות.
