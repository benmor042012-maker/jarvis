# voice-extras

שני רכיבים אופציונליים לג'רביס, בתיקייה נפרדת לגמרי. שום קובץ בפרויקט לא מייבא אותם,
ושום דבר בהם לא נוגע בקוד הקיים. אפשר למחוק את התיקייה הזאת בלי שיקרה כלום.

<div dir="rtl">

## מה יש כאן

**1. שירות מילת עוררות שרץ ברקע** — מאזין ל־"Hey Jarvis" עם `openwakeword`, מודל קטן
שרץ על המעבד של המחשב הזה. חינם, בלי חשבון, בלי מפתח, בלי אינטרנט. כלום לא נשמר לדיסק
וכלום לא יוצא מהמחשב.

**2. קול אנושי** — הקולות הניוראליים של Microsoft Edge דרך `edge-tts`. חינם וללא חשבון.

### את זה חשוב לדעת לפני שמדליקים את הקול

`edge-tts` הוא **לא מקומי**. הטקסט שג'רביס אומר נשלח לשרת של מיקרוסופט וחוזר משם כאודיו.
צריך אינטרנט, וזאת נקודת קצה לא מתועדת שמיקרוסופט יכולה לשנות בכל רגע. כל השאר בג'רביס
רץ על המחשב הזה; הרכיב הזה לא. זאת כל העסקה: קול טוב בהרבה, בתמורה לכך שהטקסט של
התשובה יוצא מהמחשב. לכן שום דבר כאן לא דלוק כברירת מחדל, ושום קובץ בפרויקט לא מייבא את
`say.py`.

אם זה לא מתאים לך — הקול שג'רביס מדבר בו היום (Settings → Voice) נשאר מקומי לחלוטין.
אלטרנטיבה ניוראלית שכן רצה מקומית היא Piper; היא חינמית, אבל קול עברי צריך לבדוק
שקיים לפני שמסתמכים עליה.

## מה הולך לאיפה

**שום דבר. כל הקבצים כבר במקום.** התיקייה הזאת יושבת בשורש הפרויקט:

```
jarvis/
├── client/            ← הקוד הקיים, לא נגעתי
├── desktop/           ← הקוד הקיים, לא נגעתי
└── voice-extras/      ← כל מה שכאן חדש
    ├── INSTALL-EXTRAS.bat       התקנה בלחיצה כפולה
    ├── ADD-TO-STARTUP.bat       שם קיצור דרך ב-shell:startup
    ├── REMOVE-FROM-STARTUP.bat  מבטל
    ├── TEST-WAKE.bat            בדיקה של מילת העוררות
    ├── TEST-VOICE.bat           בדיקה של הקול
    ├── START-VOICE-SERVER.bat   משאיר את הקול "חם" כדי שיענה מהר
    ├── run-wake-service.vbs     מריץ את השירות בלי חלון (זה מה שעולה באתחול)
    ├── wake_service.py          המאזין
    ├── say.py                   הדיבור
    ├── say.mjs                  עטיפה ל-Node, אם תרצה לחבר את זה לאלקטרון
    ├── jarvis_link.py           דיבור עם הסוכן המקומי
    ├── config.example.json      העתק ל-config.json וערוך
    ├── requirements.txt
    └── tests/test_extras.py     52 בדיקות
```

הדבר היחיד שכן נכתב מחוץ לתיקייה הזאת הוא סביבת פייתון פרטית ב-
`%USERPROFILE%\.jarvis\voice-extras-venv`, ולוג ב-`%USERPROFILE%\.jarvis\logs\jarvis-wake.log`.

## התקנה

לחיצה כפולה על **`INSTALL-EXTRAS.bat`**. הוא מתקין פייתון־venv פרטי, מוריד את החבילות
ואת מודל מילת העוררות (כמה מאות קילובייט, פעם אחת), יוצר `config.json`, ואז בודק ואומר
מה עובד ומה לא — לפני שהוא אומר "מוכן".

צריך Python 3.9 ומעלה. אם הוא לא מותקן: <https://www.python.org/downloads/> (לסמן
"Add python.exe to PATH"), או `winget install Python.Python.3.12`.

מהטרמינל, אם מעדיפים:

```
python -m pip install -r voice-extras/requirements.txt
python voice-extras/wake_service.py --check
```

## שיעלה עם המחשב

לחיצה כפולה על **`ADD-TO-STARTUP.bat`**. הוא שם קיצור דרך בתיקייה ש-`shell:startup`
פותחת (Win+R → `shell:startup` כדי לראות אותו), ומפעיל את השירות מיד כדי שלא תצטרך
להתנתק ולהתחבר. אין הרשאות מנהל, אין רישום, אין Scheduled Task — והביטול הוא מחיקה של
קובץ אחד, ב-**`REMOVE-FROM-STARTUP.bat`**.

השירות רץ דרך `pythonw.exe`, כלומר בלי חלון ובלי הבהוב של קונסולה.

## למה "Hey Jarvis" ולא "Jarvis"

ל-openwakeword יש מודל מאומן וחינמי לצירוף בן שתי המילים. למילה אחת קצרה אין מודל
מאומן, וממילא מילה אחת קצרה היא מילת עוררות גרועה — היא נורית על חצי מהדיבור הרגיל
בחדר. אם תאמן מודל משלך (`openwakeword` יודע לאמן מדוגמאות מסונתזות, בחינם), שים את
הנתיב ל-`.onnx` ב-`wake.model`.

מודלים מאומנים שכבר קיימים: `hey_jarvis`, `alexa`, `hey_mycroft`, `hey_rhasspy`.

## מה קורה כשהוא שומע את המילה

שלושה דברים, ומה מהם קורה תלוי במה שיש על המחשב:

1. **פקודה משלך** מ-`wake.command`, אם הגדרת. רצה כמו שהיא.
2. **בקשת `voice/wake` חתומה** לסוכן שרץ — בדיוק אותה בקשה שחלון ג'רביס עצמו שולח
   כשהגלאי שלו שומע את המילה. כך ג'רביס מתחיל להאזין לפקודה מיד, בלי שתצטרך לחזור על
   המילה. זה עובד רק כשסוד המכשיר קריא כטקסט.
   **ב-Windows הוא מוצפן ב-DPAPI ולכן לא קריא מחוץ לאפליקציה — וזה דבר טוב.** השירות
   כותב בלוג איזה מהמסלולים נלקח, ולא מתיימר שהעיר אם לא העיר.
3. **הרמת ג'רביס**: מפעיל אותו אם הוא סגור, ומעלה את החלון מהמגש אם הוא רץ (Electron
   מחזיק מנעול מופע יחיד, אז הפעלה שנייה לא פותחת ג'רביס שני — היא מציגה את הקיים).

2 ו-3 לא מחליפים אחד את השני. גם כשהחתומה עובדת, החלון עולה, כי מי שאמר את המילה רוצה
לראות אותו.

## הקול

```
python say.py "שלום בן, אני ג'רביס"
python say.py --list-voices he          איזה קולות עבריים יש
python say.py --out reply.mp3 "שלום"    לקובץ, בלי להשמיע
python say.py --stdin                   מדבר טקסט כמו שהוא מגיע
python say.py --serve                   נשאר חם ומקשיב על 127.0.0.1:8771
```

קולות עבריים ב-Edge: `he-IL-AvriNeural` (גברי) ו-`he-IL-HilaNeural` (נשי).

**איך הוא עונה תוך שנייה.** הדבר האיטי הוא לא הסינתזה, אלא ההמתנה לכך שכל התשובה
תיכתב. `speak_stream` לוקח טקסט כמו שהוא מגיע, חותך אותו בסוף המשפט הראשון (או אחרי
`first_chunk_chars` תווים, אם אין סוף משפט באופק), ומתחיל לדבר אותו בזמן שההמשך עוד
נכתב. האודיו של משפט 2 נטען בזמן שמשפט 1 מתנגן, כך שאין שקט ביניהם.

**למה כדאי `--serve`.** הפעלת פייתון וייבוא edge-tts עולים כמעט שנייה, בכל פעם. השרת
החם עושה את זה פעם אחת. זה ההפרש בין תשובה בשנייה לתשובה בשתיים. הוא מאזין על
127.0.0.1 בלבד:

```
POST http://127.0.0.1:8771/say    {"text": "שלום"}
POST http://127.0.0.1:8771/stop   {}
GET  http://127.0.0.1:8771/health
```

## לחבר את זה לג'רביס עצמו — אם וכאשר

`say.mjs` קיים בדיוק בשביל זה, כדי שהחיבור יהיה שורת import אחת ולא שינוי בקוד הדיבור
הקיים:

```js
import { speak } from "../voice-extras/say.mjs";
await speak("שלום בן, הכול מוכן");
```

הוא מדבר עם השרת החם אם הוא רץ, ואם לא — מפעיל פייתון למשפט הזה. הוא לא זורק חריגות
אף פעם: הוא מחזיר `{ spoken, reason }`, כדי שקול שלא זמין לא יפיל את התשובה עצמה.

שים לב שהוא **לא** מחובר לכלום עכשיו, וזה בכוונה. מי שמחבר אותו צריך להחליט מה כתוב
במסך על כך שהטקסט נשלח למיקרוסופט — ההבטחה של ג'רביס היום היא שזה לא קורה.

## הגדרות

`config.json` (נוצר מ-`config.example.json`). כל שדה אופציונלי; מה שלא כתוב לוקח את
ברירת המחדל מ-`DEFAULTS` ב-`jarvis_link.py`.

| שדה | ברירת מחדל | מה זה |
| --- | --- | --- |
| `wake.model` | `hey_jarvis` | שם מודל מאומן, או נתיב ל-`.onnx`/`.tflite` משלך |
| `wake.threshold` | `0.5` | גבוה יותר = פחות טעויות, יותר פעמים שלא שמע |
| `wake.frames_to_trigger` | `1` | 2 עולה 80 מילישניות ומוריד טעויות |
| `wake.cooldown_seconds` | `3.0` | כמה זמן להתעלם אחרי עוררות, כדי לא להתעורר פעמיים |
| `wake.quiet_hours` | כבוי | חלון שקט, כולל חלון שחוצה חצות |
| `wake.input_device` | `null` | מספר או שם מיקרופון (`--devices` מדפיס את הרשימה) |
| `wake.command` | `[]` | פקודה משלך במקום/בנוסף להרמת ג'רביס |
| `wake.launch` | `true` | להרים את חלון ג'רביס בעוררות |
| `tts.voice` | `he-IL-AvriNeural` | הקול |
| `tts.rate` / `pitch` / `volume` | `+0%` | קצב, גובה, עוצמה |
| `tts.first_chunk_chars` | `60` | אחרי כמה תווים להתחיל לדבר גם בלי סוף משפט |
| `tts.serve_port` | `8771` | הפורט של השרת החם |

## בדיקות

```
python voice-extras/tests/test_extras.py
```

52 בדיקות, ספריית תקן בלבד — הן רצות עוד לפני שהתקנת משהו. הן כוללות את החתימה של
הבקשה מול הווקטורים שיצאו מ-`desktop/src/core/util.js` עצמו, כדי שאם פייתון
וג'אווהסקריפט יסכימו פחות מבייט אחד על ה-JSON הקנוני — זה ייתפס כאן, ולא בלוג בחצות.
שלוש מהן מדברות עם סוכן שרץ באמת, ומדלגות על עצמן בשקט אם הוא סגור.

## כשמשהו לא עובד

```
python wake_service.py --check       אומר על כל אחד מארבעת הדברים אם הוא כאן
python wake_service.py --devices     רשימת המיקרופונים
python wake_service.py --once -v     מחכה לפעם אחת ומדפיס כל החלטה
python say.py --self-test            בודק את חלקי הקול בלי לדבר
```

הלוג: `%USERPROFILE%\.jarvis\logs\jarvis-wake.log`.

* **"לא שומע אותי"** — `--devices`, ואז `wake.input_device` ל-config; או תוריד את
  `wake.threshold` ל-0.4.
* **"נורה מעצמו"** — תעלה את `wake.threshold` ל-0.6, או `frames_to_trigger` ל-2.
* **"מתעורר אבל לא מקשיב"** — זה מסלול 2 למעלה. תסתכל בלוג: ב-Windows הסוד מוצפן, אז
  הוא מעלה את החלון ואומר את המילה מולו פעם אחת.
* **הקול שותק** — `pip install miniaudio`. בלעדיו הוא נופל להשמעה דרך נגן המערכת, וזה
  עובד אבל בלי חפיפה בין משפטים.
* **"הקול לא זמין כאן"** — אם יש פרוקסי או אנטי־וירוס שבודק HTTPS ברשת שלך, החיבור
  ל-`speech.platform.bing.com` נחסם ואין קולות Edge במחשב הזה. הקול המקומי שב-Settings
  ממשיך לעבוד. הקוד אומר את זה במשפט אחד במקום לזרוק שגיאה.

## עלות

אפס. openwakeword (Apache-2.0) ו-onnxruntime (MIT) רצים מקומית. edge-tts חינמי וללא
חשבון, ומשתמש בנקודת קצה של מיקרוסופט — חינמי כן, מקומי לא.
